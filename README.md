# FakeXLab — Free Fake Data Generator for Testing

Free fake data generator for software testing: generate realistic-looking fake addresses, fake names, phone numbers, emails, passwords and UUIDs — synthetic test data without using real user data. No sign-up, nothing stored, everything runs in your browser.

**Try it live: https://fakexlab.com/**

## What is FakeXLab?

FakeXLab is a free fake data generator for developers, testers and QA teams. Use it to fill signup and checkout forms, test address validation, seed demo databases, and generate dummy data for software testing and ML model testing — with fictional data only, never real people's information.

- **Fake Address Generator** — https://fakexlab.com/ — realistic fictional addresses for 39 countries

## Use cases

- **Software testing** — fill forms, test validation, checkout and signup flows
- **QA & test automation** — seed test databases with dummy data
- **ML model testing** — synthetic test data for training and evaluation pipelines
- **Demos & mockups** — realistic-looking placeholder data, no real user data

## Why fake data?

Real user data must never go into test systems. Fake data keeps tests realistic while keeping privacy safe — no sign-up, no tracking, no data stored.
