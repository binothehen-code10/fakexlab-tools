# FakeXLab Tools
Free browser-based generators for developers, testers and designers. All data is fictional and made for software testing, form validation, demos and mockups. Everything runs in your browser — no sign-up, nothing stored.

## Tools
- [Fake Address Generator](https://fakexlab.com/) — realistic fictional addresses for 100+ countries
- [Fake Phone Number Generator](https://fakexlab.com/fake-phone-number-generator/) — fake phone numbers in real formats for 30 countries
- [Random Name Generator](https://fakexlab.com/random-name-generator/) — random fictional full names, male, female or mixed
- [Password Generator](https://fakexlab.com/password-generator/) — strong random passwords
- [UUID Generator](https://fakexlab.com/uuid-generator/) — generate UUIDs in bulk
- [Lorem Ipsum Generator](https://fakexlab.com/lorem-ipsum-generator/) — placeholder text
- [Hashtag Generator](https://fakexlab.com/hashtag-generator/) — hashtags for social posts
- [Age Calculator](https://fakexlab.com/age-calculator/) — calculate age from a date of birth
